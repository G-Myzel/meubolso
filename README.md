# Meu Bolso

Um exercício simples de Python para registrar gastos, organizar por categoria e calcular totais.

## Como executar

Requer Python 3:

```bash
python app.py
```

Informe a descrição, o valor e a categoria de cada gasto. Pressione ENTER na descrição para encerrar e ver a lista e o resumo por categoria. Os registros ficam apenas na memória enquanto o programa está aberto.
